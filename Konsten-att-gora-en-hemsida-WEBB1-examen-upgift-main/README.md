# Konsten att skapa en hemsida

En webbsida som visar grunderna i webbutveckling med HTML, CSS och JavaScript.  
Sidan innehåller bland annat avsnitt om webbhistoria, lagar på nätet, HTML, CSS och JavaScript.

## Innehåll
- `index.html` - startsida
- `index.css` - CSS specifik för index.html
- `index.js` - JavaScript specifik för index.html
- `historia.html` - webbens historia
- `lagar.html` - lagar och regler på nätet
- `html.html` - HTML
- `css.html` - CSS
- `css.css` - CSS specifik för css.html
- `css.js` - JavaScript specifik för index.html
- `javascript.html` - JavaScript
- `style.css` - gemensam styling
- `script.js` - gemensama JavaScript-funktioner


## Funktioner
- Responsiv layout + header
- Navigationsmeny som öppnas med börgarmeny och har flera sätt att stängas (mindre skärmar)
- Mörkt läge
- Fullt tangentbords navigerbar
- ARIA-attributer
- Interaktiva exempel
- Många förklarande kommentarer i koden
