HTML

Vad är HTML?

HTML (HyperText Markup Language) är det grundlaggande märkspråket för att skapa webbsidor. Det används för att strukturera innehållet på en webbplats exempelvis text, bilder, länkar och andra element. HTML består av olika taggar som används för att definiera olika delar av sidan, som huvudrubriker, paragrafer, bilder, länkar och tabeller med mera.

Struktur

När man skriver ett HTML-dokument, har ldokumentet en viss struktur som måste följas. Det börjar alltid med en doctype deklaration ( !DOCTYPE html ) som talar om för webbläsaren att det är ett HTML5-dokument. Sedan följer html-taggen som inehåller hela dokumentet, och inom den finns head-taggen detta är huvudet på documentets kropp och inehåller metadatan. Sedan kommer självakroppen, body taggen den inehåller alla element som documentet består av, till exempel text och bilder, samt så bestämmer du ordningen av elementen här med i vilken ordning du skriver dem i.

Exempel på struktur i ett HTML 5 document

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta
      name="viewport"
      content="width=device-width, initial-scale=1"
    />
    <title>Document Title</title>
    <style>
    body{
      font-family: Arial, sans-serif;
      margin: 0;
      padding: 0;
      background-color: pink;
    }
  </style>
  </head>
  <body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
  </body>
</html>

Taggar

HTML bygger på så kallade taggar. En tagg är ett kommando som talar om för webbläsaren hur innehållet ska tolkas. De flesta taggar har en öppningstagg och en stängningstagg. Till exempel: 

<p>Detta är en paragraf</p>

Här är <p> öppningstaggen och </p> stängningstaggen. Allt innehåll mellan dessa tillhör elementet. Vissa taggar saknar stängningstagg, till exempel bilder: 

<img src="bild.jpg" alt="En bild">

Detta kallas för självstängande taggar. Detta betyder att stängningstagg inte behövs. Eftersom det inte finns något innehåll som ska inuti en bild, så är det inte nödvändigt att ha en stängningstagg.

Vanliga HTML-taggar inkluderar:

  • <h1> - <h6> för rubriker
  • <p> för paragrafer
  • <a> för länkar
  • <img> för bilder
  • <div> och <section> för struktur

Attributer

Attribut ger extra information om en tagg och placeras i öppningstaggen. De består av ett namn och ett värde: 

<a href="https://example.com">Besök sidan</a>

Här är href ett attribut som anger vart länken leder. Andra vanliga attribut är:

  • src – används för bilder och skript
  • alt – alternativ text för bilder (viktigt för tillgänglighet)
  • class – används för styling med CSS
  • id – unikt ID för ett element

Attribut är centrala eftersom de kopplar HTML till både CSS och JavaScript.

Semantisk HTML och tillgänglighet

Semantisk HTML är alltid bättre att andvända än ARIA-attributer om det går. Vad är Sematisk HTML då? Jo det är att man använder rätt taggar, baserat på vad innehållet är. Istället för att bara använda generella element som <div>, använder man mer beskrivande taggar som tydligt visar vad innehållet är. etta gör det änklare för andra att läsa din kod men framförallt hjälpmedel som skärmläsare.

Exempel på semantiska element är:

  • <header> – sidans huvud
  • <nav> – navigationsmenyer
  • <main> – huvudinnehåll (kan bara finnas en per sida)
  • <aside> - blurb, inehållshörtäckning...
  • <section> – grupperat inbhåll
  • <article> – artikel, inlägg...
  • <footer> – sidfot

Semantisk HTML är viktigt för tillgänglighet. Det gör att t.ex skärmläsare kan förstå sidans struktur och hjälpa användare med nedsatt syn att navigera hemsidan.

Förutom bara beskrivande divar är det viktigt att man:

  • Tydliga rubriker satta i rätt ordning (<h1> → <h2> → <h3>)
  • Beskrivande länkar (inte bara “klicka här”)
  • ARIA-attribut vid behov för extra stöd
  • alt-texter som beskriver bildens inehåll både om bilden inte kan hämtas och för skärmläsare att läsa.

Genom att kombinera semantisk HTML och god struktur skapar du inte bara en snygg webbplats, utan en som alla kan använda.

Icke-semantiskt vs semantiskt

Icke-semantiskt (dåligt exempel):

<div class="header">
  <div class="nav">
    <a href="#">Hem</a>
  </div>
</div>
<div class="main">
  <div class="article">
    <img src="hund.jpg">
    <div class="title">Mitt inlägg</div>d
  </div>
</div>

Semantiskt (bra exempel):

<header>
  <nav>
    <a href="#">Hem</a>
  </nav>
</header>
<main>
  <article>
    <img src="hund.jpg" alt="En brun hund som springer i gräset">
    <h1>Mitt inlägg</h1>
  </article>
</main>

Exempel

Här är ett enkelt exempel på en webbsida som visar hur HTML kan användas: 

<!doctype html>
<html lang="sv">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Min första hemsida</title>
</head>
<body>

  <a href="#main" class="skip-link">Hoppa till innehåll</a>

  <header>
    <h1>Min hemsida</h1>
  </header>

  <nav aria-label="Huvudmeny">
    <ul>
      <li><a href="#">Hem</a></li>
      <li><a href="#">Om oss</a></li>
      <li><a href="#">Kontakt</a></li>
    </ul>
  </nav>

  <main id="main">
    <section>
      <h2>Välkommen!</h2>
      <p>Detta är min första webbsida.</p>

      <a href="https://google.com" aria-label="Gå till Google (öppnas i ny flik)" target="_blank">
        Gå till Google
      </a>

      <figure>
        <img src="bild.jpg" alt="Beskrivande text för bildinehållet">
        <figcaption>Exempelbild</figcaption>
      </figure>
    </section>
  </main>

  <footer>
    <p>&copy; 2026 Min hemsida</p>
  </footer>

</body>
</html>

I detta exempel ser du hur olika taggar samverkar för att skapa en fungerande webbsida. Rubriker, text, länkar och bilder kombineras för att bygga upp innehållet.

HTML är grunden för alla webbplatser. När du behärskar HTML kan du sedan gå vidare till CSS för design och JavaScript för interaktivitet.

Semantisk HTML – mer än bara divar

ARIA-attribut – när HTML inte räcker till

ARIA (Accessible Rich Internet Applications) är en specifikation som låter dig förbättra tillgängligheten när vanlig HTML inte är tillräcklig. Tänk på ARIA som en sista utväg – använd alltid semantisk HTML först!

De viktigaste ARIA-attributerna

aria-label – lägg till en textbeskrivning

Används när ett element saknar synlig text men behöver en beskrivning för skärmläsare. 

<button aria-label="Stäng meddelande">✕</button>
<nav aria-label="Huvudmeny">...</nav>

aria-hidden – dölj element från skärmläsare

Användbart för dekorativa ikoner eller bilder som inte tillför information. 

<span aria-hidden="true">🎉</span>
<img src="dekor-bakgrund.jpg" alt="" aria-hidden="true">

ARIA-roller (roles)

Med role-attributet kan du ändra ett elements "betydelse" för skärmläsare. Används när du måste bygga något med <div> som borde vara en knapp eller en sök-ruta. 

<!-- En DIV som beter sig som en knapp -->
<div role="button" tabindex="0">Klicka här</div>

<!-- Ange att en div är en huvudmeny -->
<div role="menubar">...</div>

<!-- Sökfält -->
<div role="search">
  <input type="text">
</div>

Vanliga ARIA-tillstånd

Dessa attribut ändras ofta dynamiskt med JavaScript (men bra att känna till redan nu):

  • aria-expanded="true/false" – Är en meny eller dropdown utfälld?
  • aria-selected="true/false" – Är ett element valt (t.ex. i en flikmeny)?
  • aria-checked="true/false/mixed" – För anpassade checkboxar.
  • aria-disabled="true" – Elementet är tillfälligt inaktiverat.

Testa din tillgänglighet

Här är enkla sätt att kontrollera om din semantiska HTML och ARIA fungerar:

  • Tangentbordet: Kan du navigera enbart med Tab, Enter och piltangenterna?
  • Skärmläsare: Testa med NVDA (Windows) eller VoiceOver (Mac).
  • WAVE-verktyget: wave.webaim.org – analyserar tillgänglighet.
  • Webbläsarens utvecklarverktyg: F12 → fliken "Accessibility" (Tillgänglighet).
